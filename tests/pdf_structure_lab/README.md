# Стенд проверки подготовки PDF

Стенд запускает экспериментальный обработчик на копиях исходных PDF, не обращается к сайту и не меняет рабочую базу. Копии хранятся в `input/`, результаты каждого запуска — в отдельной папке `runs/`. Эти каталоги исключены из Git.

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe tests\pdf_structure_lab\run.py
.\.venv\Scripts\python.exe tests\pdf_structure_lab\verify.py
```

`run.py` создаёт текст и структурный JSON для каждого PDF. `verify.py` сравнивает символы на каждой странице с базовым извлечением pypdf без учёта пробелов и сохраняет coverage.json в папку последнего запуска. Это не доказывает правильность абзацев, пробелов, порядка колонок и содержимого изображений. PDF всегда получают статус needs_review. Многостолбцовая шпаргалка Atlassian обрабатывается ненадёжно; её результат нельзя считать готовым для чанкинга. Pro Git содержит предупреждения и требует проверки структуры. Стенд не запускает чанкинг или индексацию.
