# Контейнер Git Support

Манифест `deploy.json` описывает сервис на порту 8025, проверку `/health` и постоянный каталог `/app/data`. Он не выбирает конкретную версию образа. При ручном запуске workflow с включённой публикацией формируется тег с полным SHA коммита, который выводится в итогах GitHub Actions. Передайте Deploy Manager именно этот тег или digest, если его интерфейс поддерживает выбор версии.

Контейнер создаёт в `/app/data` SQLite, Qdrant, настройки подключения с ключом RouterAI (`.env`), токенизатор и временные файлы. Каталог должен сохраняться между пересозданиями и быть доступен процессу на запись. Существующие данные автоматически не импортируются. Токенизатор BGE-M3 загружается при сборке из зафиксированной ревизии и проверяется по SHA-256, а при первом запуске копируется в хранилище. Локальная LLM и данные пользователя в образ не входят.

Workflow запускается вручную. При выключенном `publish` он собирает образ и проверяет запуск с пустой базой и лимитом 256 MiB, затем проверяет сохранение данных при пересоздании контейнера. Проверка не моделирует индексацию и не подтверждает достаточность памяти под рабочей нагрузкой. При включённом `publish` после проверки он публикует SHA-тег через `GITHUB_TOKEN`.

GitHub Actions показывает запуск `workflow_dispatch`, когда файл workflow присутствует в основной ветке репозитория. До согласованного слияния текущей ветки потребуется другой способ проверки Linux-контейнера. Права доступа Deploy Manager к приватному пакету GHCR также нужно настроить отдельно.

Для доступа к внешнему API Python `urllib` использует стандартные `http_proxy`, `https_proxy` и `no_proxy`. SOCKS в этой конфигурации не проверен. Параметр `proxy_compatible` отражает поддержку HTTP/HTTPS-прокси.

Приложение проверяет заголовок Host и разрешает только localhost, 127.0.0.1 и testserver. Для доступа через внешний домен требуются согласованная настройка защищённого прокси и отдельная проверка доступа. Эндпоинт `/health` проверяет доступность таблицы настроек, но не проверяет Qdrant и RouterAI. Доступ к приложению и секретам должен быть ограничен средствами окружения.
